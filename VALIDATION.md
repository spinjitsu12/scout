# SCOUT 2.1.0 validation

Checked on October 2, 2026. Save schema remains version 1.

## Automated checks

- `npm run build`: TypeScript, production renderer, and desktop save validator built successfully.
- `npm test`: 30 complete three-chapter careers; 180 assisted road trips across every chapter and vehicle; physical scouting, parking, interviews, offers, assignments, payroll, fuel, roadside assistance, customization, prestige, save migration, and prologue navigation passed.
- `npm run test:desktop`: all 33 checks passed. Coverage includes durable writes, previous-save recovery, interrupted writes, offline checks, absolute network deadlines, cancellation, interrupted downloads, manifest and executable integrity, retained verified updates, and the update worker acknowledgement protocol.
- `npm run verify:release`: the portable executable identity, version, size, and SHA-256 match its manifest. Packaged updater, save validator, and every production renderer asset match the current source build. Pixel artwork and fonts are included locally; music is synthesized from bundled original scores.

## Running-app checks

The compiled game ran in Electron on Linux with the renderer network disabled and the update service simulated as unreachable. The test used the production main process, preload, renderer, and native save store. Container-only harness changes bypassed the unavailable single-instance socket and selected the portable Windows update status.

The following flows passed with no renderer errors:

- Title, Escape pause, offline update status, playable dream drive, responsive meeting rejection, firing call, walkable apartment laptop, and the first-day transition.
- Save and quit, then relaunch offline with the story, scene, style, vehicle position, and fuel preserved.
- All four driving cameras; GPS-assisted road movement and fuel use; exact car and fuel snapshots while paused; safe vehicle exit.
- A learned-benefit offer, accepted recruitment, lineup selection, evidence-based assignment estimate, successful dispatch, performance report, return to the district, and durable save.

Actual Electron AudioContext checks passed all 18 lifecycle cases, including independent engine/world controls, station switching, pause ducking, focus suspension, preference restoration, and cleanup. OfflineAudioContext rendered openings and loop transitions for all six original score/radio tracks and all three engine profiles without clipping or invalid samples. Automated scheduling checked 19,365 notes. These are render and lifecycle checks; no headphone listening claim is made.

The title, apartment, district, driving cameras, recruitment offer, assignment estimate, and performance report were visually inspected at 1280×800. A press-state transform that caused apartment and world markers to move under the pointer was fixed and retested.

## Windows checks still required

The delivered portable Windows executable was cross-built and its payload verified. It has not been launched on a native Windows machine here. The actual PowerShell executable replacement, restart, renderer-ready acknowledgement, and rollback must still be exercised on Windows. An interrupted or failed update must keep the existing executable and career usable; a successful update must reopen the same career. The installer edition does not support in-app executable replacement.

No publisher repository was supplied. This build starts with an unconfigured update channel. Gameplay and saves work immediately; background network checks begin after a public release channel is connected. Builds generated by the included release workflow embed that repository for all players.
